## 1. What this project is

Two products sharing one mission — make machine embroidery simple for a family business:

| Piece | What it is | Status |
|---|---|---|
| **Threadwell** (Windows app) | A radically simple **native Windows desktop program** for the owner's mom to prepare designs for her **Baby Lock Destiny** machine. Replaces Floriani Total Control U. | Designed (docs/01–02), prototype in `prototype/`. **Not built.** |
| **Custom Embroidery Studio** (web) | The **Lusik & Sons** order portal: big-tile catalog + live 3D stitch preview, Armenian/Spanish/English lettering, company-account invoicing + public quote requests. | **Front-end built & tested** (`apps/studio/`). Backend stubbed. |
| **The engine** (shared) | Python "name → stitches → PES file" brain used by both. | **Not built.** The single most valuable next piece. |

**The business model (docs/04):** *Lusik & Sons* (lusikandsons.com — Mom = Lusik's brand;
hand-embroidered Armenian alphabet blankets, Buena Park CA) is becoming the **contract
embroidery vendor** for **Tuxedos Online** (tuxedosonline.com — owned by the family of
**Gohar** and Gohar's father **Vrej**). They order under a company account; Lusik & Sons
invoices per order (`LS-2026-###`). The public can submit quote requests. Longer-term
vision: **white-label portals** for additional trade clients (the app is data-driven, so a
new client = a new catalog JSON + branding).

  quote*) → catalog → placement dots on product photo → name/monogram entry → **live 3D
  stitch-on preview** → send summary (invoice # for company, quote for public).

  pleated cummerbund, billowed panel (satin for jacket linings), pocket square, **terry
  cloth** for towels/robes. Thread-pattern text stitches on with a needle glint; drifting
  key light; custom touch orbit; flat panels sway; pose-return on design change; 2D
  fallback if WebGL missing.
- Lettering: EN/ES full names (print/cursive), **Armenian with live phonetic
  transliteration** ("Gohar" → Գոհար, Eastern, approximate), monogram mode (3 letters;
  Classic = last-initial-big-center etiquette, Straight, Script).

**Stubbed (the honest list — do not claim these work):**

  designed in docs/02), no order storage, public quote flow collects no contact info yet.

**Key data files:**
- `apps/studio/presets/products.json` — generated by `scripts/build-inventory.ps1`
  (PowerShell; classify on URL **slug**, never full URL — the domain contains "tuxedo").
- `data/all-products.json` — full 751-product raw inventory (reference only).
- Regenerating requires the sitemap capture; **don't re-scrape casually** — the source
  data is already committed. tuxedosonline.com returns **403 to plain fetchers** (its
  WooCommerce REST API too); the capture was done via a real browser reading
  `product-sitemap.xml` (Yoast). Product names come from URL slugs; some are cryptic —
  photos carry recognition. A "fetch real page titles" enrichment (~136 pages) is a
  known nice-to-have.
